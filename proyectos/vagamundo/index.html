Vagamundo

A travel agency for small groups, with a trip catalogue, destination guides, a travel journal readers can comment on and online booking. The React front end runs on its own Express API and a MongoDB Atlas database.

Agencia de viajes en grupo pequeño con catálogo, fichas de destino, diario de viaje con comentarios y reservas. Web en React y una API propia en Express sobre MongoDB Atlas.

Ein Reiseveranstalter für Kleingruppen – mit Reisekatalog, Reisezielen, einem kommentierbaren Reisetagebuch und Online-Buchung. Das React-Frontend läuft auf einer eigenen Express-API mit MongoDB Atlas.

01 Mi papel My role Meine Rolle
Desarrollo full stack completo: interfaz, front-end en React, API y base de datos.
Full-stack development end to end: interface, React front end, API and database.
Full-Stack-Entwicklung komplett: Oberfläche, React-Frontend, API und Datenbank.
02 El reto The challenge Die Herausforderung
Crear una agencia de viajes que funcione de verdad: reservas que nunca superen las plazas libres y una zona privada para el equipo.
Building a travel agency that really works: bookings that never exceed the seats available, plus a private area for the team.
Einen Reiseveranstalter bauen, der wirklich funktioniert: Buchungen, die nie die freien Plätze überschreiten, und ein geschützter Bereich fürs Team.
03 Lo que hice What I did Was ich gemacht habe
Front-end en React y TypeScript sobre una API propia en Express y MongoDB Atlas, login con JWT, control de plazas por salida y un panel de estadísticas.
A React and TypeScript front end on my own Express and MongoDB Atlas API, JWT login, seat control per departure and a statistics dashboard.
React- und TypeScript-Frontend auf einer eigenen Express-API mit MongoDB Atlas, JWT-Login, Platzverwaltung pro Termin und ein Statistik-Dashboard.
04 El resultado The result Das Ergebnis
Una aplicación completa desplegada en Vercel, con la que superé el módulo de Desarrollo Full Stack del máster.
A complete application deployed on Vercel, which helped me pass the master's Full Stack Development module.
Eine vollständige, auf Vercel veröffentlichte Anwendung, mit der ich das Modul Full-Stack-Entwicklung im Master bestanden habe.

Highlights Lo más destacado Highlights

  • API built from scratch with Express and MongoDB Atlas propia, hecha con Express y MongoDB Atlas selbst entwickelt mit Express und MongoDB Atlas
  • JWT authentication, with private areas for the team para el inicio de sesión y las rutas privadas del equipo Anmeldung mit geschützten Bereichen für das Team
  • Bookings Reservas Buchungen that keep track of the seats left on every departure con control de plazas libres por salida mit Übersicht über die freien Plätze pro Termin
  • Dashboard Panel Dashboard showing occupancy, prices and destinations de estadísticas con ocupación, precios y destinos mit Kennzahlen zu Auslastung, Preisen und Reisezielen
