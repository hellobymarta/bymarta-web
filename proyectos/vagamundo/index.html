Vagamundo

Agencia de viajes en grupo pequeño con catálogo, fichas de destino, diario de viaje con comentarios y reservas. Web en React y una API propia en Express sobre MongoDB Atlas.

Ver la web Código web Código API

vagamundo-web.vercel.app

1 / 5

01 Mi papel
Desarrollo full stack completo: interfaz, front-end en React, API y base de datos.
02 El reto
Crear una agencia de viajes que funcione de verdad: reservas que nunca superen las plazas libres y una zona privada para el equipo.
03 Lo que hice
Front-end en React y TypeScript sobre una API propia en Express y MongoDB Atlas, login con JWT, control de plazas por salida y un panel de estadísticas.
04 El resultado
Una aplicación completa desplegada en Vercel, con la que superé el módulo de Desarrollo Full Stack del máster.

Lo más destacado

  • API propia, hecha con Express y MongoDB Atlas
  • JWT para el inicio de sesión y las rutas privadas del equipo
  • Reservas con control de plazas libres por salida
  • Panel de estadísticas con ocupación, precios y destinos

Hecha con React 19 · TypeScript · Vite · Tailwind · Node · Express · MongoDB Atlas · Vercel
