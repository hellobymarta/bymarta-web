Casa Brava

An editorial website for a retreat of villas and suites in Kuta Mandalika, Lombok. It reads like an architecture magazine rather than a booking catalogue, and guests book by email, phone or WhatsApp.

Web editorial para un complejo de villas y suites en Kuta Mandalika. Pensada como una revista de arquitectura más que como un catálogo de reservas: las reservas se derivan a correo, teléfono y WhatsApp.

Eine Website im Magazin-Stil für eine Anlage mit Villen und Suiten in Kuta Mandalika auf Lombok. Sie liest sich eher wie ein Architekturmagazin als wie ein Buchungsportal; gebucht wird per E-Mail, Telefon oder WhatsApp.

01 Mi papel My role Meine Rolle
Diseño y desarrollo de principio a fin: estructura, textos de interfaz, maquetación y código.
Design and development from start to finish: structure, interface copy, layout and code.
Konzeption, Design und Entwicklung aus einer Hand: Struktur, Interface-Texte, Layout und Code.
02 El reto The challenge Die Herausforderung
Transmitir la calma y la exclusividad de unas villas en Lombok sin convertir la web en un catálogo de reservas, y que cargara bien en el móvil.
Conveying the calm and exclusivity of a villa retreat in Lombok without turning the site into a booking catalogue – and making it load well on phones.
Die Ruhe und Exklusivität einer Villenanlage auf Lombok vermitteln, ohne dass die Website wie ein Buchungskatalog wirkt – und das auch mobil mit kurzen Ladezeiten.
03 Lo que hice What I did Was ich gemacht habe
Un diseño editorial de 5 páginas, con HTML semántico, CSS ordenado en SUIT, animaciones con GSAP que nunca ocultan el contenido y reservas directas por email, teléfono o WhatsApp.
A five-page editorial design with semantic HTML, CSS organised in SUIT, GSAP animations that never hide content, and direct booking by email, phone or WhatsApp.
Ein fünfseitiges Editorial-Design mit semantischem HTML, nach SUIT strukturiertem CSS, GSAP-Animationen, die nie Inhalte verbergen, und Direktbuchung per E-Mail, Telefon oder WhatsApp.
04 El resultado The result Das Ergebnis
Una web publicada, accesible (WCAG AA) y mobile first, que fue a la vez encargo real y proyecto de máster.
A live, accessible (WCAG AA), mobile-first website that served both as real client work and as a master's project.
Eine veröffentlichte, barrierefreie (WCAG AA) Mobile-first-Website – zugleich Kundenauftrag und Masterprojekt.

Highlights Lo más destacado Highlights

  • 5 pages in semantic HTML5, CSS3 and vanilla JavaScript páginas con HTML5 semántico, CSS3 y JavaScript vanilla Seiten mit semantischem HTML5, CSS3 und Vanilla-JavaScript
  • WCAG AA accessibility, with technical SEO and performance built in de accesibilidad, con SEO técnico y Core Web Vitals Barrierefreiheit, dazu technisches SEO und optimierte Ladezeiten
  • Mobile first with a clean, scalable CSS architecture (SUIT CSS) con una arquitectura CSS ordenada en SUIT CSS mit einer sauberen, skalierbaren CSS-Architektur (SUIT CSS)
  • GSAP scroll animations that never hide content, even if the script fails to load en animaciones de scroll que nunca ocultan el contenido Scroll-Animationen, die keine Inhalte verbergen – auch wenn das Skript nicht lädt
