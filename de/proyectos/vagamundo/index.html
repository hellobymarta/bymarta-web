Vagamundo

Ein Reiseveranstalter für Kleingruppen – mit Reisekatalog, Reisezielen, einem kommentierbaren Reisetagebuch und Online-Buchung. Das React-Frontend läuft auf einer eigenen Express-API mit MongoDB Atlas.

Website ansehen Frontend-Code API-Code

vagamundo-web.vercel.app

1 / 5

01 Meine Rolle
Full-Stack-Entwicklung komplett: Oberfläche, React-Frontend, API und Datenbank.
02 Die Herausforderung
Einen Reiseveranstalter bauen, der wirklich funktioniert: Buchungen, die nie die freien Plätze überschreiten, und ein geschützter Bereich fürs Team.
03 Was ich gemacht habe
React- und TypeScript-Frontend auf einer eigenen Express-API mit MongoDB Atlas, JWT-Login, Platzverwaltung pro Termin und ein Statistik-Dashboard.
04 Das Ergebnis
Eine vollständige, auf Vercel veröffentlichte Anwendung, mit der ich das Modul Full-Stack-Entwicklung im Master bestanden habe.

Highlights

  • API selbst entwickelt mit Express und MongoDB Atlas
  • JWT Anmeldung mit geschützten Bereichen für das Team
  • Buchungen mit Übersicht über die freien Plätze pro Termin
  • Dashboard mit Kennzahlen zu Auslastung, Preisen und Reisezielen

Umgesetzt mit React 19 · TypeScript · Vite · Tailwind · Node · Express · MongoDB Atlas · Vercel
