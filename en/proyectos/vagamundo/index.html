Vagamundo

A travel agency for small groups, with a trip catalogue, destination guides, a travel journal readers can comment on and online booking. The React front end runs on its own Express API and a MongoDB Atlas database.

Visit site Front-end code API code

vagamundo-web.vercel.app

1 / 5

01 My role
Full-stack development end to end: interface, React front end, API and database.
02 The challenge
Building a travel agency that really works: bookings that never exceed the seats available, plus a private area for the team.
03 What I did
A React and TypeScript front end on my own Express and MongoDB Atlas API, JWT login, seat control per departure and a statistics dashboard.
04 The result
A complete application deployed on Vercel, which helped me pass the master's Full Stack Development module.

Highlights

  • API built from scratch with Express and MongoDB Atlas
  • JWT authentication, with private areas for the team
  • Bookings that keep track of the seats left on every departure
  • Dashboard showing occupancy, prices and destinations

Built with React 19 · TypeScript · Vite · Tailwind · Node · Express · MongoDB Atlas · Vercel
